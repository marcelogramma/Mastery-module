# Infrastructure

This section documents the organization's infrastructure standards, policies and conventions. These rules apply to all projects and MUST be followed by every team member involved in infrastructure provisioning, configuration and maintenance.

* [Deployment environments](<environments.html>) — Definition and rules for UAT, Production and additional environments;

* [Infrastructure as Code](<iac.html>) — Mandatory IaC approach, supported tools, template architecture and environment mappings;

* [Naming conventions](<naming-conventions.html>) — Naming rules for SAM/CloudFormation logical resource names and AWS cloud resource names;

* [Open-source preference](<open-source.html>) — Policy mandating the preference of open-source systems over proprietary alternatives.
